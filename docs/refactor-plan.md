## 目标与范围

目标是让插件更好改：拆开超大函数、理顺互相矛盾的提示词、统一换行符，同时保证 Bot 的行为不变。

要做的：

- 把超长函数拆成职责单一的小函数，主流程读起来像目录
- 逐个通读提示词，删掉互相矛盾和重复的限制，让语气更像人
- 全仓库统一换行符，以后不再出现整文件的假改动
- 隐藏的废弃配置项保留读取兼容，只整理代码里分散的兼容逻辑

不碰的：

- 功能和对外行为：发什么、什么时候发、上限多少都不变
- 数据文件格式和配置键名：升级后不需要迁移
- 安全机制：不可信资料标记、写操作结果未知不重发、权限默认关闭，全部原样保留

## 分阶段计划

分 5 个阶段，每个阶段单独发一个 PR；前一个合并后再开始下一个，任何一步停下来都不会留下半成品。

1. **统一换行符**
    - 加 `.gitattributes`，全部文本文件统一成 LF，单独一个只改换行的提交
    - 验证：`git diff --ignore-cr-at-eol` 为空，测试全过
    - 以后的阶段都在干净的换行上做，diff 只显示真改动
2. **拆开看视频流程**（`core/proactive.py`）
    - 先补「行为快照」测试：用假的 B 站和模型跑一轮，记录每一步的调用和写入的日志
    - 把 `_run_proactive_inner` 拆成：选视频 → 看和评价 → 点赞投币评论 → 推荐给主人 → 写日志和记忆
    - 特别关注流程改为复用后四步，去掉那 119 行重复
    - 验证：快照测试前后一致，原有测试全过
3. **拆开评论回复和私信处理**（`core/reply.py`、`core/private_messages.py`）
    - 同样先补快照测试，再把 7 个超长函数拆成「取消息 → 组上下文 → 问模型 → 执行结果」
    - 验证同上
4. **整理提示词**
    - 把分散在代码里的长提示词收到一个文件，按功能分组
    - 逐段删掉互相矛盾、重复的限制；安全类规则保留，风格类的「不要…」尽量改成正面说法
    - 每段改前改后放在 PR 里对照，由你定语气
    - 验证：测试全过；上线后观察几天实际回复和动态
5. **清理兜底写法**
    - 逐个判断 122 处 `hasattr` / `getattr`：真正可选的保留并加注释，其余改成直接调用
    - 废弃配置的兼容读取集中到一个函数，配置键名不变
    - 验证：测试全过，插件在 AstrBot 里能正常加载

## 风险与约束

最大的风险是拆函数时悄悄改变了行为，所以阶段 2、3 都先补行为快照测试，再动代码。

- **行为变化**：现有测试多半测单个函数，没有覆盖完整的一轮流程；快照测试补的就是这一块
- **提示词改动测不出来**：测试只能保证格式和安全规则还在，说话好不好只能上线后看；所以阶段 4 单独发、单独观察，不好就整个回退
- **换行符**：阶段 1 做完之前，改文件一律按原样保留换行，提交前看 `git show --numstat`
- **与其他人的 PR 冲突**：拆分会大范围移动代码，如果有人正在改 `proactive.py` 或 `reply.py`，最好先合了他们的再开始
- **没有真实环境**：这边只能跑单元测试，连不上 B 站和 AstrBot；每个阶段合并后需要在服务器上实际跑一下
- **网络与额度**：这台机器连 GitHub 不稳，推送可能要重试；每个阶段控制在一个 5 小时窗口内，开始前用 `/usage` 看一下剩余额度

## 新功能

两个新功能排在阶段 2（拆看视频流程）之后：STT 字幕要改同一块代码，新人引导要用到阶段 5 整理好的配置读取。

### 没有字幕的视频用语音转文字补字幕

目标是免费、用户不用多配置。现在字幕只从 B站接口拿（`core/bilibili.py` 的 `_get_video_subtitles`，B站自己的 AI 字幕也在这里），拿不到就退回看画面或抽帧。新功能插在这两步之间：

1. B站字幕（含 B站 AI 字幕）：有就直接用，和现在一样
2. AstrBot 里已经配好的语音转文字服务：用户配过就直接复用，不用再填
3. 插件里单独填的 OpenAI 兼容语音转写接口：地址、密钥、模型三项；市面上有提供免费语音识别模型的服务，README 只说明怎么填，不推荐具体厂商
4. 都没有：退回看画面或抽帧，和现在一样

实现要点：

- 音频：视频下载本来就是音视频分开的，只取音轨，用已有的 yt-dlp 和 ffmpeg 转成小体积格式，不额外加依赖
- 长视频：一个配置项「最多转写多少分钟」，超过的部分不转
- 缓存：转写结果按 BV 号和分P存下来，同一视频不重复转写
- 规矩：转写出的文字和其他字幕一样标成不可信资料，并且照样过字幕错配校验

### 新人引导

目标是装上插件的人不翻 README 也能一步步配好。现在只有 Web 面板里一条「账号未连接」提示和扫码登录。

1. 首次加载时自检：B站账号、对话模型、ffmpeg 等外部命令、各功能开关，列出还缺什么
2. 新增引导命令（比如 `/bili引导`），在 QQ 私聊里按顺序带管理员走完：扫码登录 → 选模型 → 选一套推荐配置 → 试跑一次
3. 推荐配置分两三档（比如「只回评论」「正常活跃」「全开」），一键套用，以后再细调
4. 每一步完成后显示进度；缺的东西给出具体怎么补，不只报错

待确认：这里的新人引导指的是给装插件的人用的上手引导；如果是 Bot 在 B站对新粉丝或新来评论的人打招呼，计划要另写。
